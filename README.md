# Voltryx

Static music-first website for GitHub Pages, with a secondary maker projects section.

Destination: https://github.com/voltryx-music/voltryx-music.github.io
Previous live source: https://github.com/voyce/voltryx

## Preview

Run `node serve.mjs`, then open http://127.0.0.1:4173.

## Deployment

Publish from `main` and `/ (root)` in repository Settings > Pages.
The first deployment uses https://voltryx-music.github.io/ for verification.
Do not upload the local CNAME until ready to move voltryx.com from the old repository.
The local CNAME retains that domain as a migration reference.

## Content

Music and social links are retained from the existing site. Amyboard and software
entries are placeholders pending project details; no downloads are claimed.

No build step, backend, analytics, cookies or embedded players are required.
Fonts load from Google Fonts with system fallbacks.
